# 已知问题与限制

## 构建

- 生成 MSI 需要单独安装 WiX Toolset 3.14，本仓库不包含 WiX 二进制文件。
- MSI 内置界面沿用 WiXUI 的英文对话框；产品名、快捷方式与卸载提示为中文。`installer/en-us.wxl` 将数据库代码页设为 936，以便写入中文条目。
- `light` 会输出 ICE61 警告（MajorUpgrade 未设置最高版本），不影响安装包生成。

## 运行

- 服务模式通常需要管理员权限；服务模式下 GUI 不能采集 cntlm 的 trace 日志（cntlm 服务以自身参数写日志）。
- 服务模式写入的是服务实际 `-c` 指定的 ini；解析不到该路径时会提示「请先用 cntlm 安装器创建」。
- 设置中的「启用对外互联」关闭时，生成的 ini 使用占位 `Proxy 127.0.0.1:9` 与占位凭据，仅用于满足 cntlm 启动校验。
- 明文密码写入 ini 属于兼容路径，界面会提示优先使用哈希。
- DPAPI 密文绑定当前 Windows 用户；换用户或换机器后需要重新输入密码。

## 测速

- 每个代理使用独立的临时 cntlm 实例和随机本机端口，测试顺序执行；取消或关闭窗口会等待当前测试结束并清理临时文件。
- 目标站点不可达时只反映在测速结果中，不影响代理列表本身。
- `bench` 目录中超过 6 小时的遗留临时文件会在下次测速开始时清理。
- 整链与吞吐结果依赖目标 URL 与网络环境，未在真实 NTLM 企业环境中验证完整链路。

## 安装包

- 卸载默认保留 cntlm；`REMOVECNTLM=1` 或交互选择「是」才会卸载。
- `uninstall-cntlm.ps1` 只处理注册表 Uninstall 项中显示名匹配 cntlm 且不是 CntlmGUI 的条目。
- 安装包内 `cntlm-0.94.0-win64.exe` 来自 cntlm 官方 GitHub Releases（versat/cntlm），官方未签名，可能触发 SmartScreen 提示。
- 升级安装时通过 `UPGRADINGPRODUCTCODE` 跳过「是否卸载 cntlm」的询问。

## 其它

- 主窗口为固定尺寸（880×590），设置窗口宽度固定为 620，内容超出时通过纵向滚动查看。
- 托盘图标常驻；系统注销/关机或安装器 Restart Manager 请求关闭时会真正退出，不会隐藏到托盘。
